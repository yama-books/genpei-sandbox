# SIM-03：資源不足と延期後の再判断

2026-10-20 JST / Codex / `feat/genpei-sim03`。起点は最新 `origin/main` の `fab0ec44c3f27a3d0ccbd7b1b30023e107d3ee20`。
[SIM-02感度分析](SIM_02_SENSITIVITY_20261020.md)を正本とし、結末比率の目標は設けない。

## 選んだルール

交戦には従来の余力46点に加え、義経本人の体力15以上・食料12以上を必要とする。丸め前の実値で比較し、士気や同行者による欠乏の相殺を防ぐ。15/12は既存coreの低体力移動・士気低下の境界を参考にした**ゲーム用の候補値**で、史実や人体の閾値ではない。

交渉は既存の助言受諾・余力37点・現地在場の条件を維持する。攻撃できないことと交渉できないことは別に扱う。延期理由は既存 `fate.decisions[].causes` に疲労・食料欠乏・総合余力不足を記録する。

既に屋島で延期した人物は、15刻の猶予を経た後なら屋島の外でも準備を再評価する。不足が続き交渉の余力もなければ `withdrawal`（屋島外で攻勢を断念）。屋島にいれば従来の `retreat`（現地で撤退）とする。回復して屋島外にいる場合は `reconsidered` を一度記録して本人の帰還を待ち、交戦・交渉は起こさない。延期期限の延長、移動先の変更、強制瞬間移動、追加乱数はない。相手が退避済みなら屋島外の延期者は機会喪失の `withdrawal`、現地の遅参は既存の `empty`。章締切112刻は常に優先する。

未延期で屋島を離れた人物は従来どおり自由に行動し、訪問履歴だけで戦闘や撤退を発火しない。生活・施設選択・歴史的引力・介入予算・時計・戦闘得点式を変更しない。

|floors|15/12|なし|欠乏の相殺は解消するが、屋島外の延期問題が残る|

予備32シードで先に比較し、`reconsider` を選択して本体へ反映した後、別の128シードによる確認比較を開始した。両集合はSIM-01/02の128シードとも重複しない。各段階で全候補を同じシード・同じ条件に対応させる。確認結果による閾値の再調整は行わない。

11条件（通常、POIなし、有限3介入、交渉助言、食料0、体力10、所持金0、複合不足、複合不足＋支援、起点施設、中間施設）×引力0/50/100×4ルール。複合不足は体力40・食料20・所持金0を同時に設定した交互作用条件。全ケース240刻、独立再実行の全遷移ハッシュ・最終状態と30刻JSON保存復帰を照合する。生活件数は章確定後も含む全3人物の240刻合計である。

## 状態別検証と従来条件

[状態別プローブ](sim-03-probes.json)は各候補300状態。SIM-02と同じ資源・士気・同行者・助言の組合せで、体力0でも交戦する8状態、食料0でも交戦する4状態が各0になった。体力0の交渉14状態・食料0の交渉11状態は維持。各単独資源0の分母は60状態であり、自律プレイの発生率ではない。今回の自律比較標本では対照にも最低資源未満の交戦は出ていない。このため欠乏の相殺への改善根拠は、状態プローブと14.9/15・11.9/12を含む直接テストである。

各候補48状態の時間・在場プローブも記録した。直接テストで猶予前後、屋島外の不足、回復後の帰還、交渉だけ可能な状態、退避・締切、延期中JSON保存復帰、解決後の生活継続を確認する。

従来のSIM-01と同じ128シード×POI有無×引力3水準×有限介入有無の**1,536ケース**では、[SIM-03結果](sim-03-improved.json) / [CSV](sim-03-improved.csv) / [表](sim-03-improved.md)の全セル集計と全シードCSVがSIM-01結果に完全一致。通常条件での生活・結末・全遷移ハッシュを維持した。これは不足や延期が起きる全条件の不変性を主張しない。

SIM-01/02の過去成果物は書き換えず、当時の `fate.mjs` を検証fixtureとして固定し、既存のハッシュ・結果との照合を継続する。CIの浅いcheckoutでも再現可能。新ルールの再現検査は別テストで実施する。

## 限界と境界

三人物・固定初期位置・CC0-1.0の合成4施設。歴史確率・実道路・人物GPSを生成したものではない。シード対応は共有乱数の消費順まで揃えるものではなく、経路や介入による後続乱数の違いを含むシナリオ比較である。有限観測で停止0でも永久停止しないとは証明しない。実店舗の収集・外部経路API・史料台帳の改変はない。

UI・地図・共有workflowは変更しない。`getAgentPlacement` の `positionDomain:"abstract"` / `realGeo:null` を維持し、既存 `withdrawal` と `retreat` の意味を引継ぎへ記す。iPhone Safari実機・mainマージ・本番公開は対象外。
