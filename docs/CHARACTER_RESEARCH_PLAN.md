## 1. 名簿の取扱い

前回の会話では「120人」と概算されていたが、**当時は機械的な重複整理・人数確定を行っていない**。本ファイルは会話に挙がった名前を改めて群別に転記した「候補」であり、確定した史実上の人数ではない。下記の表の候補数は本書の登録見出し数であり、別名・同一人物・伝承上の人物などの照合後に改訂する。

「登場人物に採用する」「歴史上実在が確認できる」「伝承の記載が確認できる」「出来事が史実と認められる」は、**互いに異なる判断**である。

**この名簿に載っていることだけを根拠に、人物の存在や合戦参加を確定してはいけない。**

## 2. 史料・証拠区分

このA〜Dはプロジェクトで用いる予定の**監査用ラベル案**であり、学界共通のランクではない。

| 区分 | 意味 |
| --- | --- |
| A | 対象人物について同時代の史料の該当箇所を確認できた |
| B | 後世史料や研究に根拠があるが、同時代記録を未照合 |
| C | 実在性や同定に研究上の論点がある |
| D | 主として軍記・芸能・伝承上に現れ、史実としての同定はできていない |
| 未監査 | 根拠資料本文を確認していない（初期値） |

**重要**：人物がAでも、ある逸話がAであるとは限らない。属性・系譜・出来事・場所の**個別主張ごとに**監査状態を持つ。等級を上げるには確認済み出典の該当条文・ページと判断理由が必要。主張には `reviewStatus: pending | checked | human-confirmed | disputed` を持たせる。

## 3. 史料の優先的な調査経路

1. 同時代の日記・文書・記録（例：『玉葉』『吉記』『山槐記』など）と、その確かな翻刻・解説。
2. 『吾妻鏡』等の後世編纂史料（編纂時期・政治的立場を踏まえて読む）。
3. 『平家物語』諸本・『源平盛衰記』等の軍記（本文異同と文学的構成を記録）。
4. 専門研究書・大学研究・公的博物館展示の出典解説。
5. 地方史・寺社縁起・口碑・後世の物語（成立時期と伝播を管理）。

例として国立公文書館の展示は『平家物語』と『玉葉』等の相違、軍記諸本の相違を明示している：
- https://www.archives.go.jp/exhibition/digital/heikemonogatari/
- https://www.archives.go.jp/exhibition/digital/heikemonogatari/contents/20.html
- https://www.archives.go.jp/exhibition/digital/heikemonogatari/contents/24.html

外部資料を参照しただけで人物個票を「確認済み」にしない。出典の**該当箇所を特定したとき**だけ確認済みにする。

## 4. 登録フィールド

### 人物 Person

- person_id（英数字の不変ID）
- primary_name、reading、aliases（通称・官職名・異体字、同一人物の根拠）
- birth_date / death_date（不明・範囲・諸説ありを扱う）
- sex_or_gender_as_attested（史料にない属性は創作しない）
- lineage（出自・氏族）と faction_memberships（時期依存の軍事所属）は別管理
- relation_ids（父母・兄弟姉妹・配偶者・子・主君・家臣・同盟・敵対）
- place_claims（出生地・成長地・本拠地・所領・活動地・死没地を別々に）
- events（戦闘・交渉・移動・婚姻・宗教・文化等）
- portrayals（軍記での人物像。史実の心理状態とはしない）
- evidence_status（人物同定の段階）と review_status、reviewed_by、reviewed_at

### 個別主張 PersonClaim

- claim_id, person_id, predicate, value
- earliest_source_date（可能なら）
- source_id、作品・巻／段／年月日条／頁、翻刻などの版
- quote_excerpt_or_summary（著作権に注意、短い要約を優先）
- statement_kind: historical_record | gunki | legend | modern_inference
- certainty / conflicting_claim_ids
- proposed_by / review_status / reviewer_note

### 地理情報

`place_role = birthplace | upbringing | residence | base | battle | death | burial | memorial | legendary_association` のように役割を明記。史料に「出生地」がない場合、屋敷跡や本拠地を出生地へ転用しない。現在座標は史跡資料で確認した範囲に限る。

## 6. 特に注意する人物・論点

- **那須与一**：軍記上の「扇の的」と同時代史料による実在の確認を分離。下野の那須氏の歴史と、物語の与一像の関係を監査する。
- **武蔵坊弁慶**：記録上の言及・人物同定と、五条大橋や立往生などの後世の物語化を区別。
- **巴御前**：軍記・地域伝承上の人物像と実在の同定を切り分ける。
- **平教経**：一ノ谷／壇ノ浦等の最期に諸説。時期条件なしに1185年屋島へ登場させない。
- **源義経**：軍記の英雄像と実際の軍事指揮・経路・奥州関係を区別。
- **源範頼**：義経だけに西国作戦の功績を集約しない。
- **平徳子・平時子・安徳天皇**：同一人物ではなく、死亡・生存・入水・戦後の出来事は別々に扱う。
- **木曽義仲**：頼朝の家臣として初期から固定しない。独立勢力との関係が重要。
- **千葉常胤**：氏族の平氏系統と頼朝への政治軍事的協力を混同しない。
- **平頼盛**：平家一門でも主流派との政治的行動が一様ではない。
- **東国・西国の在地武士**：姓で「源氏／平氏」の二陣営へ機械振分けしない。
- **藤原景清**：実在の活動・系譜と芸能の景清像を区別。
- **安徳天皇・義経の生存伝説**：史実とは別の伝承シナリオ群に入れる。

## 8. 作業フローと完了条件

1. 候補名を正規化し、別称・同一人物・同名異人を解決する（元表記は消さない）。
2. 人物一人につき出典を調べ、**実在に関する主張**と**個別逸話の主張**を別レコードで起票する。
3. 重要な人物関係・生没・所属時期・地理主張を二次資料から一次史料へ可能な限り遡る。
4. 異説・出典間不一致は単一値へ潰さず併記し、「保留」表示を許す。
5. 人が典拠位置と叙述を確認するまで `reviewStatus: pending` にする。
6. 人確認済みデータのみ史実として表示。未監査人物は「候補」「軍記人物」「伝承人物」として別表示する。
7. 検証用 fixture を作り、年代矛盾、循環する親子関係、出典欠落、同一人物二重登録を検出する。

## 9. 今後の保存形式

現段階はMarkdownを調査正本とし、機械可読データ（`data/people/*.yaml` など）はスキーマと監査運用を確定してから派生生成する。人物IDは変更しない。ゲーム内の能力値や娯楽嗜好は別の `game_personas` に置き、史料台帳の内容に混ぜない。

**次の具体的成果物**：第1群の人物個票、個別主張の典拠監査表、主要事件年表、地点・人物関係グラフ。これがMVP人物データの採用審査に必要。
