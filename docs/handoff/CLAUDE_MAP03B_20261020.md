## 2. 実装済み・検証済みの内容

### 実装

- 現代地図ビューの下に「施設間の現代経路（プレビュー）」パネルを追加した。
- 画面要素：
  - 出発施設と到着施設の選択、入替ボタン
  - 照会できるかの判定（MAP-03Aの `makeModernRouteRequest` の結果）と、直線距離（「道路経路ではありません」と明記）
  - 取得・消去ボタン
  - 結果表示：経路長、出典、ライセンス、取得時刻、「人物の移動ではない」旨
- 経路の端点にできるのは、`world.modernPois`（採用中）と `buildModernStations(loadedModernPois)`（採用可）の和集合だけ。施設は名称と実座標の組で照合する。参照のみ・架空地点・史跡・人物は選べない。
- `prototype/map/route-provider.mjs`（新規）
  - `resolveRouteProvider(location.search)`：既定は `none`。`?route=fossgis` で FOSSGIS OSRM の徒歩経路（評価用）、`?route=local&routeEndpoint=<localhost系のURL>` で自前OSRM。
  - `buildOsrmRouteUrl`：施設2件の経度,緯度だけでURLを作る。
  - `osrmToContractAnswer`：OSRMの応答を `modern-route/1` の形式に変換する（確実性は `estimated`）。
  - `createRouteClient`：リクエストを直列化し、最小間隔（FOSSGISは1100ms）を守る。成功した経路だけメモリにキャッシュする。12秒で時間切れ。送信時は `credentials:"omit"`。
  - 応答は必ず `reviewModernRoute` の審査を通し、通ったものだけを描く。失敗の理由は `ROUTE_FAILURE_LABELS` の日本語文で表示し、線は描かない。
- `modern-map.mjs` に `showRoute` / `clearRoute` / `hasRoute` を追加した。
  - 経路は専用レイヤーに、クラス `map-route-preview` の線として描く。ツールチップは「人物の移動経路・1185年の道ではありません」。
  - 経路の出典表示は、線を表示している間だけ出典欄に加える。
- 端点の変更・入替、施設が候補から外れたとき、古い応答が届いたときは、線を消す。

## 4. 経路・地図データの出典・ライセンスと公開リスク

- **FOSSGIS OSRM**（`https://routing.openstreetmap.de/routed-foot/route/v1/driving/`）
  - 認証は不要で、CORSは全オリジン許可（2026-10-20に実測）。
  - [about](https://routing.openstreetmap.de/about.html) の記載：1秒1回まで、大量利用・スクレイピング禁止、正当なUser-Agent/Referrerが必要、保証なし。
  - ブラウザからはUser-Agentを設定できない。Referrerは `strict-origin` でオリジンだけを送る。
  - ドイツ語の正式な利用規約（fossgis.de）は、ボット対策で取得できず**未読**。公開版で有効にする前に、FOSSGISへの確認を推奨する。
- **データ**：OpenStreetMap（ODbL-1.0）。線を表示している間は「© OpenStreetMap contributors」と著作権ページへのリンクを表示する。経路はリポジトリに保存せず、メモリのキャッシュだけで扱う。
- **APIキーが必要なサービス**（openrouteservice：Directions 2000回/日・40回/分、要帰属。GraphHopper：無料枠500クレジット/日、非商用）：GitHub Pagesの公開JSにキーを置けないため、今回は使っていない。
- 既存のLeaflet 1.9.4（BSD-2）、地理院タイル、OpenPOIの出典表示はそのまま。
- **公開リスク**：
  - `?route=fossgis` は誰でもURLに付けて使える。共用サーバーへの負荷は利用者ごとに1秒1回まで、かつ同じ組み合わせはキャッシュするよう抑えているが、利用者が多い場合の総量は制御できない。公開版で案内する前に判断が必要。
  - 経路は「現在の道路データによる推定」で、通行可否・安全・営業は保証しない。所要時間は、ゲーム時間との混同を避けるため表示していない。
