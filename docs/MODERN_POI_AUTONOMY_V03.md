# 現代施設の自律行動への統合 v0.3

記録：2026-10-19 ／ 範囲：屋島周辺1.2km、最大50件取得からゲームに採用する最大12件。
実際の中世道路や現代の道路ネットワークを再現するものではありません。

## 1. 今回の到達点

1. OpenPOIの「周辺施設を取得」を押すと、屋島史跡全体の代表点（北緯34.3566、東経134.1012）を中心に、現代施設の名前・住所・分類・座標・データ出典・ライセンス・帰属表示を読み取る。
2. 「行動候補に追加」を押した**場合だけ**、自律行動する3人の目的地候補に反映する。取得だけでは行動も変わらない。
3. 画面には施設名と出典・帰属表示、および模式図上の現代施設マーカーを描画。実際の施設座標を参考にした簡略配置だが、背景地図や線は正確な地理ではない。
4. 現代施設で食事・食料調達・休息・見物する行動を仮のルールで処理。空腹・疲労・所持金・好奇心によって目的地の優先順位が変わる。
5. 施設での行動は元の観察日誌に記録され、体力・食料・士気・所持金へ反映。その結果は屋島篇の「運命の刻」の準備度や時機にも波及する。
6. 「行動候補から外す」、リセット、セーブ・復帰に対応。セーブは従来どおりページ内一時保存。
7. 観察日誌から「現実の出費ではない」等の冗長な説明を削除。

## 2. 情報源と信頼できる範囲

- 施設提供元：OpenPOI API。公式仕様 https://docs.openpoiapi.com/
- データには実在施設の名称・現代の緯度経度・所在地・OpenPOI内部のカテゴリと出典を使用。
- クエリ：`GET /v1/search?center=134.1012,34.3566&radius=1200&limit=50`
- APIの実応答確認（2026-10-19）：カフェ、観光、宿泊、食料関係などの候補を含む。ただし**データがあることは、現在の営業・施設への進入可否・正確な位置を保証しない**。
- 出典・ライセンス・帰属が欠ける施設は自律行動の候補には組み込まない。
- 元カテゴリがunknownなどの場合は未分類として残し、勝手に飲食や宿泊へ推定変換しない。
- 取得データはブラウザのメモリに保持。現時点でAPIから得た全施設のスナップショットをGitHubに固定保存しない。実例の店舗名をコードに埋め込まない。
- API仕様上、CORSの全オリジン許可・認証不要を確認。ただしブラウザ実通信は通信環境とAPIの状況による。

## 3. ゲームと現実を分ける境界

**現実由来**：施設の名称・カテゴリ・住所・座標・出典・ライセンス。

**ゲームの仮設定**：施設を目指す心理、移動距離・速度、道の接続、食事・買物・宿泊費、体力回復、士気上昇、合戦への間接効果。

現代施設の座標は`modernLocation`とし、画面内の`x,y`へ暫定投影するだけ。施設までの**徒歩経路や距離・所要時間として解釈してはいけない**。実施設カテゴリから、ゲーム内で必ず食事ができる・入館できるなどとも断定しない。

`prototype/poi-world.mjs`の分類・効果をゲーム規則として管理し、`prototype/openpoi.mjs`のデータ取得処理と分離。実施設のPOIを勝手に更新・予約・決済する動作はない。

## 4. 行動候補の選び方

- 重複名＋近似座標を除去。利用候補は上限12件。
- 飲食4件、食料購入3件、休息2件、見物3件をカテゴリ別に上限設定。
- 本当の料金情報は取得していないため、ゲーム内の費用は一律の仮設定。
- 出典不備、unknownなど行動種別を決められない施設は不採用。
- 仮施設の補給・娯楽・休息は残し、現在の試作品の挙動を壊さない。
- 施設の採用・解除による行動リストは各人の次の目的地再評価から有効。
- 同じシードと同じ施設集合で、同じ操作・介入が行われれば行動と結末は再現される。ただしAPI結果や並びが変われば初期条件が変わる。

## 5. 旧国名エンジン・地図との将来連携

地理情報は3層に分離する。

1. **時代・出典の意味情報**：屋島史跡ID `YS001`、1185年頃、讃岐国等。共通旧国名エンジンがIDと時代の定義を提供する。
2. **現代POIの実在座標**：OpenPOIのWGS84緯度経度・帰属。将来の道路経路エンジンとの接続を待つ。
3. **現在の試作用移動空間**：独立した仮想座標。歴史地理エンジンから変換した「1185年の道」を主張しない。

次工程で必要なもの：現代地図ビュー（道路と施設のPOI）、現実の経路検索、歴史地理レイヤー、移動速度のゲーム設計。旧国名エンジンを複製しない。

## 6. テストと次のゲート

- `tests/poi-world.test.mjs`：分類、出典・許諾、重複、到着時の食料・出費、資金不足、解除、再現性。
- `tests/headless-smoke.mjs`：模擬OpenPOI API応答を返し、取得・追加・解除・リセットがPC幅／スマホ幅で動くか確認。実店舗情報には依存しない。
- 実APIの読み取りは別途確認。公開UIでボタンを押した実ブラウザ試験と、iPhone Safari実機の視認性検査は独立した受入項目。
- 次の主要な実装テーマは、見せる模式図を「現代地図モード」と「歴史地理モード」へ分け、施設をクリックして出典・効果・経路の確実性を表示すること。

この時点で、中世の海岸線や港・街道・旧国境界を推測で描画しない。
