状態：コード作成済み。ブラウザ実機での操作・表示検証、およびGitHub Pages公開の確認は未実施。

## 操作と対象

- 屋島篇の核心11人を切替。人物の説明は上流の人物索引CSVと33主張CSVをブラウザで取得して表示する。
- 人物の主張ごとに出典ID、URL、確認状況、留保事項を表示する。これは史実の最終確定ではない。
- **移動するのは義経・佐藤嗣信・那須与一の3人のみ**。その他8人は人物資料カードとして閲覧する。
- 運命の引力の強弱（0～100）、再生／停止／1刻進行、速度変更、シード変更・リセットを操作できる。
- 人物への「屋島へ向かうよう助言」（拒否の可能性あり）、「資金・食料支援」（計3回まで）を試せる。
- 保存・復帰はページ内の一時メモリのみ。ページを更新すると消える。

## 起動方法

リポジトリのルートからPython標準HTTPサーバーなどを起動：

    python -m http.server 8000

その後、 http://localhost:8000/prototype/ にアクセスする。

**HTMLのファイル直開きは未対応**。人物CSVはfetchで相対パスから取得する。GitHub Pagesは設定されていれば /genpei-sandbox/prototype/ のURLになるが、現在は有効化・公開の確認をしていない。

## コアエンジンの範囲

core.mjsでは人物別の仮想初期位置・体力・所持金・食料・好奇心・歴史的引力を使って目的地の効用を比較し、得点上位の場所へ移動する。選択には一部の確率的な寄り道を含むが、乱数シードを保存し、同じ条件なら同じ結果になる。施設訪問で資源・時間を消費し、残金不足なら利用できない。直前に訪れた施設は連続再訪問を抑制する。

**すべての位置・人物特性・移動速度・現代施設・金額・因縁係数はゲーム実験用の架空の値。** 史実の心理や現実の距離、施設の営業・在庫・運賃を示さない。屋島・阿波・海上などのノードは模式図上の記号であり、実際の座標や海岸線ではない。

歴史イベント・人物の死亡／戦闘・個人／部隊の分離・交通ネットワーク・OpenPOI連携・継続セーブ・分岐間の比較は未実装。

## 屋島篇「運命の刻」v0.2（2026-10-19）

- [仕様・分岐条件・旧国名エンジン接続口](../docs/FATE_CHAPTER_V02.md)
- 施設への寄り道、補給不足、未到着でも世界の時間が進む。屋島の**現在の仮想位置**と決断の時機が揃ったときに、戦闘・交渉・延期などを人物が自律判定。
- 決断を延期しすぎると交戦が不成立になり、章の期限が来れば「何も起こらなかった」ことも結末となる。
- **人物の自由行動は続く**。章の判定は固定され、その理由とこの周回で経験した出来事を表示。
- 新操作「交渉を勧める（義経）」は受諾確率があり、必ず交渉を成立させる強制指示ではない。
- 旧日本国名エンジンへの接続口 `geography-bridge.mjs` は、地名と時代・出典の検証契約のみ。1185年の地図や道路は取得・推定していない。
- 旧来の`tests/prototype.test.mjs`に加え、`tests/fate.test.mjs`の分岐テストを実行する。

## 現代施設の自律行動への接続（v0.3）

- OpenPOIの検索結果を「行動候補に追加」でゲームへ投入できるようにしました。「行動候補から外す」で解除可能。
- 実在施設の名称・座標・カテゴリ・出典・ライセンスを保持。食事・調達・休息・見物に対応する分類だけを採用（最大12件）。用途・出典が未確認の施設は自動使用しません。
- 人物が施設へ移動し、利用により食料・体力・士気・所持金が変化。屋島篇の結末にも結果が反映します。
- [実装仕様・制限・旧国名エンジンとの境界](../docs/MODERN_POI_AUTONOMY_V03.md)を参照。
- **施設の位置は現代座標に基づく暫定的な模式配置。道路網、施設の営業、実際の価格、11～12世紀の経路ではありません。**
